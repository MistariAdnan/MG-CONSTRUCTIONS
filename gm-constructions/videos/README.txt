HERO VIDEO (optional)
1. Download a free house-construction video from pexels.com/videos, pixabay.com/videos or coverr.co (search: "house construction").
2. Pick 720p, keep it under about 5 MB (short 10-20 second loop is best).
3. Rename it hero.mp4 and put it in this folder.
The home page plays it automatically (muted, looping). If the file is missing, the site shows the photo instead.
